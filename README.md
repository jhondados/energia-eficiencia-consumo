# ⚡ Eficiência Energética com IA

> Plataforma de eficiência energética que analisa o consumo, detecta desperdícios e recomenda ações de economia para indústrias, comércios e o setor público.

**🌐 Demo ao vivo (web app interativo):** https://jhondados.github.io/energia-eficiencia-consumo/

[![Setor](https://img.shields.io/badge/Setor-Energia-blue)]() [![IA](https://img.shields.io/badge/IA-ML-green)]() [![Demo](https://img.shields.io/badge/Demo-Interativa-orange)]() [![Dados](https://img.shields.io/badge/Dados-CSV%2FExcel-success)]()

## 📊 Resultados-chave (KPIs)
**-23%** Economia · **detectado** Desperdício · **-18%** CO2 · **payback 9m** ROI

## 🧠 Tecnologias de IA
ML · Optimization · IoT

## ✨ O que faz
- Análise de consumo
- Detecção de desperdício
- Recomendação de economia
- Metas de eficiência
- Relatório de sustentabilidade

## 🗄️ Fonte de dados real
[ANEEL + medição](https://www.gov.br/aneel) — bases de entrada e resultados disponíveis para download em CSV/Excel no app.
